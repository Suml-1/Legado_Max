# 更新日志

### 2026-10-25 竖屏全屏隐藏小窗按钮

- 播放器：竖屏视频全屏播放时，底部控制栏的小窗按钮自动隐藏——全屏与竖屏共用一个控制栏布局，
  但竖屏视频的全屏画面本身就是竖向的，再切小窗没有收益，留着反而占底栏位置
- 播放器：横屏视频全屏时该按钮照常显示，位置与行为不变（下一集右侧）

### 2026-10-24 选集面板与倍速面板对齐

- 播放器：选集面板与倍速面板结构一致（同为透明容器 + 全高纯文字列表、项高 46dp）
- 播放器：选集面板加宽到屏幕宽度的 45%（原 30% 的 1.5 倍）——剧集标题普遍较长，30% 下被省略得难以分辨；
  倍速面板仍保持 30%，它只有"1.0X"这类短文本
- 播放器：修复选集面板"当前集"没有加粗高亮的问题——此前只把列表滚动到当前集位置，没有把它交给列表项渲染，
  导致当前集与其它集在视觉上没有区别；现在当前集用阅读主题色原色并加粗，其余项同色压暗

### 2026-10-23 选集 / 倍速面板改为纯净文字样式

- 播放器：选集与倍速面板去掉整块深色底板与"选集/倍速"标题条，改为**透明背景**——只有文字叠在画面上，不再切出一条生硬的深色竖带
- 播放器：列表项去掉卡片底色与白色描边圆角，改为**纯文字条目**（此前每一项都像一颗按钮，与播放器画面割裂）
- 播放器：面板文字统一使用**阅读主题色**——当前档位为主题色原色并加粗，其余项为同色压暗，层级靠文字本身表达，不再用色块区分
- 播放器：面板宽度 40% → 30%，贴合"细窄侧栏"的观感，同时仍能容纳较长的剧集标题（超长自动右侧省略）
- 播放器：列表项高度统一为 46dp，一屏可显示更多集数，点击区域依然充足
