# 阅读界面帮助文档

## 阅读界面主菜单

- 顶部操作
  - 章节名称:点击可编辑书源
  - 章节url:点击可打开浏览器浏览
  - 菜单:**不同类型的书籍显示的菜单不同**。详情请查看菜单文字,长按菜单图标可显示文字
- 中间左侧-亮度调节
  - 亮度调节的顶端有跟随系统亮度的开关,打开后亮度跟随系统,关闭后才可以调节亮度条
- 底部操作
  - 4个圆形按钮依次为 全文搜索✧自动翻页✧替换净化✧切换夜间模式
  - 上一章✧下一章中间的进度条为页数进度,要快速跳转章节点击目录按钮进入目录快速跳转
  - 目录->目录和书签界面
  - 朗读->单击开始朗读,长按进入朗读设置界面
  - 界面->所有排版设置都在里面
  - 设置->其它一些设置,找不到的设置去这里看看,可滚动

## 全文搜索

搜索本地缓存或者本地文件，不能搜索在线内容  
书籍字数、净化规则数量、简繁转化、文章分段都会影响到搜索速度，请酌情启用

## 朗读设置界面

- 后台->进入后台朗读,可以做一些其它事
- 设置->朗读引擎设置,可以切换本地TTS和在线朗读,在线朗读可自定义

## 排版设置界面

- 白天模式和夜间模式背景不同布局相同
- 开启「启用墨水屏渲染」(我的-主题设置-通用设置) 后,阅读页背景与文字仍随日/夜切换:日间取墨水屏(E-Ink)那一档,夜间取夜间那一档
- 共用布局->启用共用布局时所有背景使用同一布局,关闭共用布局则每个背景单独布局
- 长按背景可进入文字颜色和背景设置界面
- 字重->点击字重控件进入字重切换界面
  - 粗略调整:正常/粗体/细体三档
  - 精细调整:100~900 连续可调,正文和标题分别设置;需要 Android 9 及以上,首次切换会给出提示
  - 系统字体:先按系统提供的真实字面取最近的粗细;字体给不出的那部分字重(中文回退常常只有
    常规/粗体两个字面)会用描边外扩加粗、背景色擦除变细补上,所以中文也能连续调
  - 第三方字体:大多是单一字面,比常规更粗靠描边外扩实现、更细靠"字后面实际颜色"描边擦除实现
    (高亮色块/当前搜索命中块用块色,其余用页面背景均色);因此"细体"需要能确定字后面的颜色
  - 可变字体(带 wght 轴的)直接给出连续字重,不需要补

## 正文标题分段

- 入口:阅读界面 -> 界面 -> 信息 -> 正文标题 -> 分段模式
- 让正文顶部的章节标题按指定模式换行分段,只改变正文里标题的显示,不改章节名本身
- 四种模式:
  - 关闭:不分段,标题按原样显示;此时「分段内容」「次行字号」「标题行距」收起
  - 按位置分段:填数字,在该数字对应的字数后换一次行(如填 5,前 5 个字一行,其余一行);数字超出标题长度时不分段
  - 按标记分段:填字符,标题里每个该字符处换行,字符本身保留在前一行末尾;填写内容按字面使用,空格和 `|` 都能当标记,需要按多种标记分段时用正则模式
  - 按正则分段:填正则表达式,每个匹配项的后面换行,匹配到的内容保留;正则不合法时按原样显示
- 次行字号:分段后第 1 段之外的行算次行,字号按首行字号的倍数调节(0~2 倍,小于 1 比首行小,大于 1 比首行大);未开启分段时该项收起
- 标题行距:分段后的标题各行之间用这个行距,与正文的行距、段距无关(量程与调节方式和正文行距一致);未开启分段时该项收起
- 只影响正文标题的显示:页眉页脚、书架章节名、目录、朗读标题仍按原标题显示,替换规则的匹配与正文首行去重的判断也不受影响
- 分段模式、分段内容、次行字号、标题行距都跟着排版走,会随阅读样式一起备份恢复,也能随分享排版导入导出

## 页眉页脚自定义

- 入口:阅读界面 -> 界面 -> 信息
- 页眉、页脚各有左、中、右三个位置,点击任意位置打开模板编辑框
- 模板里可以混排普通文字与占位符,点编辑框下方的占位符按钮即插入到光标处
- 可用占位符(中英文写法等价,括号内为英文写法):
  - `{书名}` / `{bookName}`
  - `{章节}` / `{chapterTitle}`
  - `{时间}` / `{time}`
  - `{电量}` / `{battery}`,显示为百分比,如 `85%`
  - `{电量图标}` / `{batteryIcon}`,按电量填充的电池图标
  - `{电量图标数字}` / `{batteryIconLevel}`,图标内部显示电量数字
  - `{页码}` / `{page}`
  - `{总页数}` / `{totalPages}`
  - `{阅读进度}` / `{readProgress}`
  - `{章节序号}` / `{chapter}`
  - `{章节总数}` / `{totalChapters}`
- 示例:`{页码}/{总页数}  {阅读进度}`、`{时间}  {电量图标}`
- 旧版本选择的规则(如"时间""电量")会自动换算成等价模板,无需重新设置;某个位置一旦手动编辑过,就以模板内容为准

## 其它设置界面

- 屏幕方向
- 屏幕超时
- 隐藏状态栏
- 扩展到刘海
- 隐藏导航栏
- 文字两端对齐
- 文字底部对齐
- 标点允许出现在行首->开启后无视中文标点禁则,行满时按宽度正常断行,逗号、句号等收尾标点可以出现在行首(同时不再做行尾开引号下移与连续标点压缩);该开关会使排版切换到自定义中文分行引擎
- 保留空行->开启后正文与书源网页里原有的空行会保留下来(最多连续保留 5 行),用来表达停顿与场景切换;默认关闭,关闭时连续空行会被合并成一个,正文更紧凑;切换后当前章节会重新排版
- 音量键翻页
- 点击翻页
- 朗读时音量键翻页
- 自动换源->书源被删除时自动切换到其它书源
- 长按选择文本
- 显示亮度调节控件
- 点击区域设置
- 自定义翻页按键
