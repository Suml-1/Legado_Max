> 本目录存放**长期有效**的模块架构说明、设计方案、技术笔记与测试/验证方法论——回答"这块现在是怎么做的 / 这类事该怎么做"。
> 与之相对：一次性改造方案 / 计划 / 根因分析归 [`docs/archive/`](../archive/)，项目级强制规范归 [`docs/project-rules/`](../project-rules/)。三者不要混。
> **维护约定（与 [docs/project-rules/README.md](../project-rules/README.md) 同理）**：新增文档后必须登记到本索引，不允许文件躺在目录里没人知道；遵循"文档是导航不是契约、以代码为准"。
